# 🛡️ CodeAlpha - Basic Network Sniffer

## 📌 Project Overview
This project is a **Basic Network Sniffer** developed as part of my Cyber Security Internship at CodeAlpha.

The program captures live network packets and displays essential information such as IP addresses, protocols, and ports to understand how data flows through a network.

## 🎯 Objective
- Capture network traffic packets  
- Analyze packet structure and content  
- Understand basic networking protocols  
- Display useful packet information  

## 🚀 Features
- 📡 Capture real-time network packets  
- 🌐 Display Source & Destination IP addresses  
- 🔍 Identify protocols (TCP, UDP, Others)  
- 🔢 Show source and destination ports  
- 📦 Display packet payload (basic view)  

## 🛠️ Technologies Used
- Python 🐍  
- Scapy
